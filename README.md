# Anon Portfolio

Personal portfolio for **Hossain Simum Anon** — AI Content Specialist.

Live at **[anon.anonsagent.com](https://anon.anonsagent.com)**.

## Stack
- Next.js 14 (App Router), React 18, TypeScript
- Tailwind CSS 3 + lucide-react icons
- Deployed on Vercel

## Run locally
```bash
npm install
npm run dev
```

Built as a standalone project (separate from the Anon's Agent publication site).
